## 1. Authority and bounded purpose

This preflight is the scoped G2-F contract subordinate to the Current
Architecture Lock. The authority order is the explicit owner authorization,
the Current Architecture Lock and accepted current Gate/runtime bytes, the
Document Authority Index, the Successor Context Manifest and current lifecycle
surfaces, Gate-Based Roadmap v3.1 as HOW/WHEN, Master Technical Roadmap v2.1 as
technical WHAT donor, and historical evidence last. The binding roadmap ruling
is `ACTUAL_PAIR_IS_V2_1_AND_V3_1`; no v2.5/v3.5 source is required.

G2-F is the consolidated Gate-2 gauntlet and operational-closure acceptance
surface. This Class-A hop reconciles the accepted V12R2/V12R6 181-row public-only
geometry into the seven current control-plane surfaces. It does not implement
that orchestration, authorize G2-F runtime work before the exact owner Class-A
commit and a later separate authorization, close Gate 2, or authorize staging,
commit, or push by anyone except the owner.

The seven binding Gate-2 completion statements are:

1. safe informational reuse skips heavy work;
2. action-like reuse remains blocked;
3. high-risk multi-Root work selects the deep path;
4. an authorized packet can be revoked before fulfillment;
5. an old packet cannot replay after supersession;
6. one changed fact causes complete and minimal selective recomputation;
7. ModeRouter, DRS, packet registry, and child cells create no authority.

No kernel primitive, schema, Living act, Conformance category, provider,
model, network, connector, adapter, or real effect is added. BSEP remains the
semantic membrane, RuntimeExecutionTopology remains runtime-owned, and every
Root remains independently sovereign. There is no SuperRoot.
