# Design and production notes

This presentation package was prepared on 13 September 2026 from the accepted Testflix V11 implementation and the original V09, V10 and owner-execution records.

## Visual direction

The design uses white and soft gray surfaces, graphite text, generous spacing and a restrained blue accent. [Apple Events](https://www.apple.com/apple-events/) provided the visual reference for a calm presentation hierarchy. This is an independent Radiolaria presentation, without Apple branding or endorsement.

[Inter](https://rsms.me/inter/) is the typeface. Regular and Bold font files are included for offline HTML use under the accompanying SIL Open Font License. The PDF documents embed their used Inter glyphs. The PowerPoint deck declares Inter; install the bundled fonts for consistent editing on another computer. Font substitution can change layout in other slide applications.

The cover sculpture is generated conceptual artwork. Its prompt and original asset identity are in `assets/hero_art_provenance.json`. It is not a screenshot, a runtime topology or an execution artifact.

## Reader formats

- The 18-slide PowerPoint is authored with native editable text and tables. The cover is a raster illustration.
- The companion PDF is exported from that PowerPoint with searchable text. Table border rendering may vary slightly between slide applications.
- The one-page executive summary and ten-page Technical Appendix use searchable text and embedded fonts.
- The offline HTML presents the verified evidence in a responsive reading layout. It does not execute the Testflix runtime.
- The XML reader embeds selected source bodies and accepted code with exact SHA-256 identities. It is a portable review entry point, not the full original archive collection.

## Evidence treatment

Presentation prose is newly written in English. Original captured responses remain unchanged, including historical refusals and failures. Labels distinguish copied records, selected-field extracts and archive-only references. The claim matrix maps claims to source records, selectors and slides.

Presentation creation adds no model-provider call, business effect or project-runtime test. The generated cover illustration is an editorial asset and is separate from the recorded Testflix model-call ledger.
