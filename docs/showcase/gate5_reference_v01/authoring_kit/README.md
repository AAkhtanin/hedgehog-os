## 2. Choose and state WHAT separately

The published example task is [WHAT_TO_BUILD.md](../../../gate5_authoring_kit_v01/WHAT_TO_BUILD.md) plus [FOOTBALL_PROFILE.md](../../../gate5_authoring_kit_v01/FOOTBALL_PROFILE.md). The generic HOW transfers supported construction mechanisms; it does not claim that one paragraph can generate any system in any language. The original START_HERE, inventories and HOW retain their freeze-time dates and pending descriptions. G55L later admitted the exact accepted source; no historical file was silently rewritten.

## 3. Keep the evaluation boundary visible

Give a blind author only the chosen general construction surface and its declared task profile. Exclude the finished football pack, hidden examiner, oracle answers, supervisor evidence and this audit reader. [AUTHOR_TOOLS.json](../../../gate5_authoring_kit_v01/AUTHOR_TOOLS.json) describes the recorded broker surface; it is not a deployment or account provisioning service. The author may create a candidate; a different authority reviews and admits it. The existing static [candidate_contract.py](../../../gate5_authoring_kit_v01/candidate_contract.py) reads package data without importing candidate code. Its success is only a shape result, not permission to execute or install the candidate.

The [accepted football pack](../../../../hedgehog/domains/football_pitch_booking/pack_v01/) is a separate worked example for an informed reader. Do not include it covertly in a new blind trial. It has 23 authored files plus a broker-produced `candidate.json`.

## 4. Use the environment and execution contract deliberately

Read [DEPENDENCIES.json](../../../gate5_authoring_kit_v01/DEPENDENCIES.json): it records the measured Python 3.14.5 environment and installed metadata, not a package lockfile or automatic installation permission. The kit source closure and actual schema resource are included. Existing numeric/mock commands are documented in the original entry. They execute native work or a disposable mock effect and require an independently approved reviewer environment; publication of these commands does not authorize arbitrary candidate code.

For inspection of already saved Gate 5 evidence, use the distinct [offline verification route](../VERIFICATION.md). It creates no new candidate, author, model, native Work or effect. The two pure verifier processes and file reads are explicit.

No owner admission context, secret or key is part of this handoff. The actual [AGPL-3.0 license text](../../../gate5_authoring_kit_v01/LICENSE) remains exact. Repository links currently require authorized private-repository access.
