## Execution

Three sequential semantic duties propose needs, obligations and privacy findings.
The PersonalRoot accepts the route before the architect consumes a local BSEP
projection. Model outputs contain semantics, never authority or resource handles.
Two actual common Work items compile and consume a typed command contract. The
second item consumes the first item's actual output, and its result supplies the
session's operation gate. This is common Work execution, not full fractal D/E.

One PersonalRoot/Host persists for the session. Each new consequential command
gets a scoped native packet, public Root decision, public lifecycle installation,
current Host dispatch and real admitted execution. There is no model call, D/E
run or U2 revision per click. OPEN never grants permission to later commands.
Local PNG writes, subprocess IPC and sidecar writes are MOCK_CONSEQUENTIAL;
external device/business effects are zero. This classification is not a claim
that local side effects are pure or that same-UID processes are OS sandboxes.

The trusted source samples monotonic elapsed time at intake and before use.
Each command has at most 120 seconds, narrowed by the parent lifetime. The
executor also checks that exact packet's actual expiry immediately before its
finite effect, independently of time spent validating the packet. Capture
time is local observation, not external clock attestation. Controls cannot
supply the current clock. Historical receipts do not confer present permission.

## Resources And Privacy

A source/render subprocess receives only scoped synthetic paths and hashes.
A separate display subprocess receives derived PNG bytes and opaque frame refs.
Loopback IPC uses separate credentials, strict message versions, finite payloads,
session identity and monotonically increasing sequences. Display exposes no
source or listing endpoint. Owner confirmation and untrusted control UI use
distinct loopback origins. Raw model outputs and launch credentials are private.

The finite PNG/IPC invocation is the cancellation boundary. END or lifetime
expiry stops intake and invokes initial resource-owner cleanup obligations.
Owned children are reaped through retained Popen handles. Preview cleanup checks
device/inode/hash and preserves replacements. Already downloaded pixels cannot
be remotely erased. A cleanup conflict reports CLEANUP_INCOMPLETE, not success.
