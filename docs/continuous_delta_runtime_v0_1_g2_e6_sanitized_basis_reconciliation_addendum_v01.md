preserves those 16 acts in exact order and appends
`continuous_delta_runtime` at position 17.

`all_layers_invariant_super_smoke` remains historical evidence only. It is
never restored to current execution, rebound into a current profile, or used
to manufacture an obsolete act or reference position.

## 4. Single-collection and shared-report law

A direct top-level Conformance report collects exactly one current public E5
report, validates it through the public E5 validator, and passes that exact
validated report into its internal builder.

A top-level Living report also collects exactly one current public E5 report,
validates it publicly, derives its Living act from it, and passes the same
sealed and canonical report into the internal shared Conformance builder. The
shared builder publicly validates the received report again and never
recollects E5. Each independent top-level call obtains a fresh report; no
global cache, process-persistent reuse, stale report, test fixture, or
cross-invocation sharing is allowed. Proof binds sealed canonical identity and
bytes, not Python object identity.

Neither consumer imports tests, calls private G2-D functions, reconstructs
E5's cases, copies PASS, or invokes a second delta runtime. The operational
hang guards in the metadata are dead-process protections only and are not
latency, performance, Gate, release, or production claims.
