Set portable variables outside this kit; no personal paths are required:

```sh
export PYTHONDONTWRITEBYTECODE=1
export PYTHONPATH="$KIT/source"
"$PYTHON" -B "$KIT/example/run_numeric.py" "$NEW_OUTPUT"
"$PYTHON" -B "$KIT/example/check_effect.py" "$NEW_MOCK_OUTPUT"
"$PYTHON" -B "$KIT/example/reconcile_receipt.py" "$NEW_MOCK_OUTPUT"
"$PYTHON" -B "$KIT/candidate_contract.py" "$CANDIDATE"
```

The first command runs two actual native calculations with a changed input and a
refusal. The next changes only a disposable local two-record MOCK snapshot via
the native effect boundary, tests refusal paths, then reads its saved receipt.
These commands must not be used as an execution authorization for unknown code.
They create new output directories; preserve failures rather than overwriting.

The source snapshot is an AST-derived local import closure plus the actual Work
schema resource. An initial dry run identified that missing resource; it is now
included and the complete example succeeded from the snapshot alone. No .git,
owner context, secrets, target implementation or examiner fixture is included.
Static source may expose more functions than this kit supports. Only the mapped
public seams and stated finite donor profiles are claimed, not every imported
module or arbitrary callback behavior.

Numeric source contains no allocation, scheduling or booking logic. The MOCK donor
is the attributed G50 two-record example; its original IDs are retained for source
attribution, not authority. The G52 adapters are declared calibration donors:
their high-level role names and operation modes are not generic placeholders.

The author-visible manifest excludes task values, examiner cases and supervisor
evidence. The complete return archive is for the supervisor/reviewer only; never
give that whole archive to the author. Freeze changes require a new kit/trial
version. Source admission and native capability admission are separate decisions.
