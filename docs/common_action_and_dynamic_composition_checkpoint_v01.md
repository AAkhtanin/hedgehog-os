# Bounded Common Action, Retained Work and Local Pure Capability Reuse

## What This Implementation Enables

This exact admission proposal composes reviewed U1-U4 implementation on H
`20d16af823ed4af94dc0a342c731aef81e8a23de`, parent C
`19de35c3b77725c4763b33cbac5c42118fd3c382`. It is not yet owner landing or
independent final acceptance. Historical Gate2 C remains its bounded accepted
integration, not proof of arbitrary tasks. No new architectural Gate is added.

Native nonpayment and legacy payment packets use the same genesis, consumption,
revocation, supersession and present-eligibility laws. Playback, alarm and
payment remain distinct subject operations, not one business transaction.
The [native packet builder](../hedgehog/action_commit_packet_v02.py) retains
typed action/capability inputs. The [current host dispatcher](../hedgehog/work_execution_host_v01.py)
checks current task revision, Root scope, code and designated actual input
validation before STARTED. Only the [Effect Firewall](../hedgehog/kernel/effect_firewall_v01.py)
owns the bounded effect handle. Missing/rejected inputs cannot be replaced by
a plausible final answer or a caller's PASS string.

The [work materializer and handler](../hedgehog/kernel/work_composition_v01.py)
resolve actual declared result fields before Root action authorization. D's
review is exact-work CONTROL: it binds semantic proposal, dependencies, budget,
guards and work identity, but cannot grant permission. An independent owning
Root authorizes the resulting action after its actual inputs exist. See
[composition tests](../tests/test_work_composition_v01.py) for the real field
consumption and changed/missing producer controls.

Continuation revises the same task from actual intermediate results, preserving
completed invocation/result/artifact history rather than replaying completed
effects. Retained immutable D/E results supply evidence in canonical slots;
current namespaces and cumulative budgets remain validated independently.
Old accepted output never creates present execution rights.

A missing pure capability can be generated in the controlled finite profile,
admitted and consumed in that same task, stored in local DRS, rediscovered by
need, and readmitted without a warm generator call. The
[admission boundary](../hedgehog/capability_admission_v01.py),
[closed worker](../hedgehog/wasm_pure_worker_v01.py), and
[memory binding](../hedgehog/capability_memory_binding_v01.py) remain distinct:
retrieval is not admission, and admission is not Root action permission.
