# From Intent to Governed Activity

Radiolaria OS organizes computation around a continuing task. The fourteen chapters move from that purpose to the common relationships, inspect three concrete episodes, and return to what an integration team can build and verify. They explain complementary profiles, not a single execution combining every case.

## 1. Computing, Assembled Around Intent

A useful task lasts longer than a model response. Radiolaria relates purpose and significant conditions to the Work actually performed, while keeping result acceptance and action consent distinct. A small Football example opens the argument: a permitted schedule change produces a useful offer, but booking remains a new decision.
