# Exact originals, safe navigation and exclusions

Original included files retain their exact bytes, size and SHA-256. Archive-member identities map them to their capsule-relative reading paths in the detached manifest. New extracted tables and guides are labeled editorial or safe projections with an original file identity and JSON pointer. Their hashes identify the new view, never replace the original's hash.

The mandatory original AT5 package and execution receipts contain generic historical command paths such as macOS temporary directories and a generic administrator project path. These strings are inert execution provenance, not public links or working commands. They are not rewritten because that would break source identity. All new navigation uses stable capsule-relative paths or repository URLs pinned to the implementation commit.

Russian operator directives, owner instruction files, actual review contexts, credentials, configuration files, secrets and personal HOME contents are excluded. A filename mentioned by archived code is not itself a copied configuration file. The deliberate synthetic privacy canaries in controlled tests are evidence, not harvested personal data.

The canonical 68 MB proof package is embedded exactly once. Earlier complete package copies, recursive historical archive trees, duplicate runtime projections already contained in that package and unnecessary transport archives are not copied. Their original archive identities and source-impact relationships remain traceable. The included source bindings disclose the selected source scope and any bodies not supplied; no full import closure is implied.

Binary witnesses are stored byte-exact in the companion capsule and represented by identity, description and relevance in XML. No large base64 image body is placed in the reading stream. A detached index records every member's id, path, kind, provenance, bytes, hash, encoding, position and case/claim associations. The manifest/index do not recursively hash themselves.
