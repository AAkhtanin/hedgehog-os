03 / 02 / THE TASK

The local monitoring task

Observe, investigate, act locally, and explain what happened.

  • Changes in rainfall alter the next monitoring interval.
  • Fresh local evidence can justify a bounded signal while optional reasoning is still pending.
  • Recovery requires new measurements and a separate OFF decision.
Technical explanation and source bindings

The task is not to have a chatbot announce a landslide. It is to keep a bounded local monitoring process coherent across changed evidence and optional dependencies. A synthetic slope supplies rainfall, displacement and an independent reserve channel. The site coordinates a finite catalogue of diagnostic operations and monitoring actions. It can ask an analyst which investigation would resolve the present uncertainty, but that response does not set thresholds, invoke an arbitrary sensor, modify the Host or authorize a signal. The chronological S0-S5 story exercises configuration, changed rainfall, roles, outage and signal, queued report delivery, measured recovery and local semantic memory. Separate latest live experiments establish real semantic producer-to-consumer relationships that the controlled whole story does not claim to demonstrate. 04 / 03 / THE THESIS

Replaceable intelligence
and local authority

The model is a contributor inside the cell.

  • Reasoning proposes a finite investigation.
  • The runtime binds sources, requirements and actual work.
  • Root remains the sole final authority; Host and Firewall enforce effects.
Technical explanation and source bindings

The architecture separates a semantic role from the physical engine that supplies its contribution. A local algorithm, a future local SLM or a cloud model can fill a permitted role with truthful provenance. Sentinel uses common semantic-work DTOs and trust profiles to validate a contribution, common BSEP/router boundaries for current meaning, actual Work execution and independent Root review. Root is neither the Gemini response nor the deterministic diagnostic function. A Root acceptance of information does not automatically create permission. When an effect is needed, a separate current action packet, live Host state and admitted capability validation are required. The point is local responsibility with replaceable reasoning, not a claim that the demonstrated software is a certified landslide-warning system. No generic execute-code, arbitrary source URL, policy-writing model capability or public emergency endpoint is part of this demonstration. The topology here is a conceptual explanation of the source-bound cell, not an exact rendering of every native graph artifact.
