# Ephemeral Workspace

**Radiolaria OS | v0.1 | 14 September 2026**

## A temporary computer assembled around a task.

Semantic intent. Local authority. Bounded resources. Verifiable evidence.

## The demonstrated lifecycle

A request becomes a working photo and media environment: browse, rate and select photographs; adjust exposure and crop; review finite video and audio. Typed semantic contributions are consumed by real Work. Local Root decisions authorize consequential actions. A model proposal and a Bounded Semantic Evidence Packet (BSEP) carry evidence, never action permission.

The principal scripted desktop/mobile run deliberately removes AudioSink. A fresh observation arrives 86 seconds after the old packet expires. Selective recomputation changes the affected media branch without extending old authority or discarding completed photo work. Silent playback adds 12 frames and zero PCM samples. A separate approval authorizes exactly one 250-byte sidecar. Originals remain unchanged; owned resources close.

## What the evidence establishes

- **Meaning changes behavior.** Historical mixed and photo-only requests produce different bounded contracts. Historical Gemini responses and captured reexecution retain their own provenance.
- **Memory does not restore permission.** Historical LocalDRS reuse requires current eligibility and fresh Root review. Changed context blocks stale recipes.
- **The boundaries are inspectable.** Twelve scoped requirements comprise five current production-boundary probes and seven carried historical positions.
- **Verification is portable.** Eighteen public package files and a separate publication are preserved. Independent-pin offline replay reports ANCHORED_PASS for the safe derivatives.

## Measured, with scopes intact

Principal D preparation: 113.1 s. E: 300.1 s. Complete browser launcher: 14 min 27 s. Landing retained 27 implementation files and 19 frozen public evidence files byte-for-byte. These measurements overlap and are not a production latency promise.

## Scope and limits

Fixture media; scripted browser actions; three controlled deterministic semantic responses in the principal run; zero principal provider calls. No arbitrary application generation, physical-audio proof, general OS sandbox or production certification. Native original canonical-reference replay remains UNSUPPORTED_NATIVE_SCHEMA. Safe-derivative integrity does not establish private-original semantic truth or live Host origin. Overall EWS acceptance is not self-awarded.
