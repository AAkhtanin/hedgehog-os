## Selection, inertness and limits

Python source files from the return archive are copied **byte-for-byte** but named `*.py.txt`. This is solely a filename change; the old and new names and identical SHA-256 appear together in `SOURCE_MAP.json`. All copied files have mode `0644`. They are historic data. They are not installed under `hedgehog/domains/`, imported by this publication, or executable as delivered. A reader should parse the JSON and text as evidence and should not execute embedded code or example commands merely to inspect the case.

The corpus omits 586 original archive members, among them large raw app-server event and tool-result dumps, protocol schemas, nested worker tarballs, process stdout/stderr and private synthetic canary/sentinel bytes. It retains the complete restricted broker journal and four candidate generations as well as the relevant peer evidence. The authoritative archive SHA above and the original manifest permit an independent reader with the full return archive to check the omitted records. This selection cannot independently establish an absence of hidden provider-side capabilities or all omitted execution details.
