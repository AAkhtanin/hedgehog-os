# G36R Semantic Proof Repair

This is an engineering correction after observing G36's incomplete chronology,
not an original pre-observation experimental protocol. The frozen four requests,
raw replies, policy, reference fixture and numerical laws remain unchanged.

## R1: Review Before Learning, Execute After Work

ADV-1 and ADV-2 use ordinary canonical construction, Root review and accepted
bound construction with installation disabled. No source mutation, pending
lifecycle or dispatch is performed. Verified native facts distinguish accepted
PREPARED_NOT_DISPATCHED proposals from Root refusals and completed effects.
ADV-3 retains its actual installed historical packet and expired refusal.
CONTINUE consumes the selected successful Work on the same Host, then uses
ordinary fresh Root/Host action preparation. Redispatch checks the consumed key.

## R2: Substantive Provenance

The scope capability still checks the proposal against the independent policy.
The stronger capability also checks finite request/response/claim identities,
prospective timing, model/Root/lane/subject compatibility, exact source/event
bindings, and the Root-permitted history read and current bridge. Its output
contains checked facts and specific refusal reasons, not a self-awarded pass bit.

New corrected history snapshots carry compact review_source_projections derived
from independently validated source-bound events. The existing Root record pins
the exact snapshot; the existing public DRS descent opens that same payload.
The Work input rows must equal these projections. Rehashing a substituted reply
and its claim cannot preserve that equality. Legacy snapshots omit this field and
retain their previous shape and canonical identities. Cold start explicitly has
no linked history. Full native mechanism material is not embedded in Work inputs.

## R3: Original Experience Versus Delivery

The original outcome is retained verbatim and pinned independently of the new
delivery. Sample identity binds the original request, response hash and ID,
model, prospective claim, Root and subject. History uses the original outcome
time; the new native boundary keeps its actual clock, source ID and receipts.
Repeated deliveries have distinct source-bound event IDs and duplicate audit
entries but one effective sample. Historical comparisons declare their original
evaluation time; fresh current eligibility and decay are not bypassed.

## R4: Supplied Relations

Full CurrentReviewContract values are validated and related to reconstructed
pure source context, claims, checks, projection, actual Work inputs and outputs.
Saved contracts must agree. Ordered Host spans bind registry and event histories
from initialization through review, expiry, history, Work, final effect and
redispatch. Root refusal and pure Work cannot mutate the action registry.
ADV-4 records the attempted foreign feedback, write and lookup plus exact refusal
and unchanged history/retrieval evidence. Replay uses the same extracted pure
source-membership and Root-key predicates as the actual history consumer, never
a new Root decision or a restored Host.

## Additional Observed Pointer Defect

The first corrected controlled attempt stopped at public DRS history admission.
Its generated snapshot hash contained the consecutive digits 95432002196538;
the unmodified DRS guard classified the reference as potential card material.
The exact generated-digest path now falls back to a reversible a-p nibble
alphabet only after that public refusal. Arbitrary text cannot enter this path.
Both the producer and descriptor consumer still use the existing public pointer
builder. Existing accepted references stay byte-exact. No secret detector or
authority rule was changed. The first attempt and the diagnostic are retained.

## Evidence Boundaries

Four original Gemini acquisitions are historical evidence. The corrected
captured episode creates a new Host and performs new native controlled work; it
does not reconstruct the old Host or constitute a fifth provider sample.
Pure replay validates saved relations without provider, current Root, Host,
Work execution, current history writes or effects. Full native graph replay
remains unsupported. G37, owner admission, commit, push and Gate3 closure are
not performed by this repair. Final outcomes are reported only after receipts
and finalizers complete.
