# Testflix: короткая демонстрационная история

Все суммы ниже в minor currency units. Реальны ответы настроенной Gemini,
их локальная привязка к запросам, вычисление, Root review и доказательства.
Каталог и время контролируемые, покупки и устройства являются моками.

1. Клиент предпочитает AD_FREE при лимите 650. Интерпретатор фиксирует намерение,
   аналитик разбирает условия каталога, selector предлагает план 500,
   reviewer независимо проверяет предложение. Их разные реальные outputs
   видны в раскрываемых записях viewer. UserRoot, BankRoot, ProviderRoot и
   DeviceRoot решают каждый за себя; после native execution начинается playback.
2. Информационный запрос использует сохранённые допустимые результаты.
   Stop и новая сессия не превращаются в повторную покупку и не меняют Hosts.
3. В controlled P04 уже ожидает настоящий quote-bound пакет на 500. Новая
   цена 700 наблюдается позже; доверенная current evaluation также позже,
   но исходный TTL пакета ещё действует. Старый пакет отказывается до эффекта.
   Общий public E пересчитывает затронутую ветвь за 318.0 с,
   сохраняет unaffected paid period. Новая BankRoot review отказывает при 650.
4. Независимая ветка 600 действительно проходит другой E за 318.9 с,
   получает новую review/packet и один mock payment. Это не третий платёж
   основной истории. Coherent N15 mutations и неверные time/binding отказываются;
   законные эквивалентные inputs проходят.
5. На точном expiry прежнее право не используется как текущее. Новое явное
   согласие 700 запускает отдельный renewal. Live-роли реально потребляют
   обновлённые условия и лимит, затем новые Root decisions и receipt создают
   новый оплаченный период. Stop/fresh-session внутри него не добавляют платёж.
6. Итог основной истории: те же четыре Hosts, два mock payment. Seal и offline
   replay проверяют старую/новую историю без provider/effect calls и без
   присвоения текущего разрешения из памяти.
7. Первый A/B закончился реальным разногласием ролей. Владелец разрешил дополнительные
запросы; уточнён общий QUALITY input contract, предикаты отказа не ослаблены.
Два новых ответа intent/terms сохранены, но selector получил два Google504,
затем httpx.ReadTimeout после увеличения server/client deadline до180с.
Проверены публичный input-bound resume и SDK server-deadline; результат не выдуман.
Положительное A/B-потребление НЕ завершено, точные транспортные ошибки сохранены.
8. Captured-handler заново проходит тот же сценарий с реальными новыми Hosts,
   сохранёнными input-bound responses и 0 LLM calls. Остальные canonical поля
   истории совпадают; четыре явных mode fields отличаются по смыслу provenance.
   Это новый mock execution, не просто просмотр seal.

Один ранний реальный model refusal сохранён: неясная исходная task projection
вызвала запрос лишних данных. После уточнения предмета/единиц validator не был
ослаблен; такой ответ всё ещё отказывает. Всего 18 попыток/15 ответов, 13 принятых role outputs.

Открыть `story.html` можно без сервера и сети. Полная live история заняла
19.6 мин; модель не объясняет основную локальную стоимость
history validation. Это конечный проверенный пример, не универсальная или
production certification. Independent review/admission/owner landing остаются.
