05 / AUTHORITY

Root reviews the route and each effect

Semantic acceptance

The route returns to Root with explicit evidence, constraints and unresolved issues.

Current action

Each consequential command receives a finite packet, current Root review and Host/Firewall validation.

Route acceptance does not grant permission to later commands.

Technical explanation and sources
The runtime normalizes bounded claims and assembles evidence, checks, policy, time and permission state for the public Root decision kernel. Route acceptance happens before architect consumption. For a consequential command the system constructs a fresh finite packet, binds the actual local Root result, installs its lifecycle in the persistent Host and dispatches through the Effect Firewall. Neither model output nor an old receipt is a reusable grant. The BSEP explicitly records the rule: Gemini proposes, Root disposes.
