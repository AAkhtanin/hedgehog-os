The idea in one transaction

Reasoning can help.
Authority stays explicit.

A user asks for a streaming plan. Models interpret the preference, read the terms, propose a choice and review it. That choice then enters an actual kernel and Host workflow.

The model's recommendation becomes validated input. Each Root still owns its own decision, and every effect must satisfy the current contract.

Testflix is a finite, reviewed demonstration domain. The provider is fictional; no Netflix purchase, real payment or physical television action occurred.

Evidence: ab_consumption · main_result

Four semantic duties

One request.
Four different questions.

Each role receives the relevant projection and consumes the ordered upstream records. A disagreement remains a disagreement until the input contract is clarified.

01

Interpret intent

Express the supplied preference and priorities; identify missing required evidence.

Cannot: Create payment authority.

02

Read the terms

Project each supplied plan and determine eligibility against the explicit price ceiling.

Cannot: Change catalogue facts or the budget.

03

Propose a plan

Consume intent and terms, select an eligible plan and explain its trade-offs.

Cannot: Execute its own proposal.

04

Challenge the proposal

Check the selection against the same request and upstream evidence; disclose blocking conflicts.

Cannot: Override an independent Root decision.

Four independent authorities

A recommendation
does not spend money.

The subscription crosses user, bank, provider and device responsibilities. Each Root reviews the evidence for its own boundary.

UserRoot

Accept the purchase selection for the user.

BankRoot

Review the payment action against current terms and consent.

ProviderRoot

Authorize entitlement issuance using the payment receipt.

DeviceRoot

Authorize playback within the current session and device grant.

The same four Hosts retain the main lifecycle history. An informational request or a fresh playback session does not create another subscription payment.

What is controlled

  • Finite catalogue
  • Local test clock and time observations
  • Bank payment effects
  • Provider entitlement effects
  • Device playback effects

This does not establish an actual Netflix purchase, external time attestation, arbitrary-domain universality, production certification or automatic renewal.
