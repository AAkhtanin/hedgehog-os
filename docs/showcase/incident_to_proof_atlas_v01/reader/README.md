# Radiolaria OS — Incident-to-Proof Atlas

Work adapts. Authority stays with its owner.

Radiolaria organizes bounded, compositional work around an intention. Semantic participants propose; runtime materializes and executes eligible Work; independent owners retain their local decisions. Current time, changed conditions and available resources constrain continuation. Memory carries applicable experience, and outcome feedback can change the next selected and executed Work without changing who may authorize an effect.

The Atlas exposes these relationships through five controlled domain demonstrations. It is one architecture examined through twenty finite cards, not twenty independent learners. Read the product and its useful continuations before interpreting individual refusals.

## Reading route

1. `reader/PUBLICATION_STATUS.json` separates original AT5 evidence, independent review, AT6 source landing and this unpublished presentation build.
2. `presentation/slide_text_and_notes.json`, the technical appendix source and `presentation/cards.json` provide the editorial reading layer when listed PRESENT in `presentation/INTEGRATION_STATUS.json`. Missing editorial inputs are explicit, never silently represented as complete.
3. `reader/CASE_ROUTES.json` indexes all twenty cards and fifteen risk families. `reader/CLAIM_ROUTES.json` maps C01–C18 to exact package pointers and saved controls.
4. `reader/WORKSPACE_W4_D1_ROUTE.md` follows one complete story: closed memory → independent current task → actual completed Work → exact current approval → one local save.
5. `reader/CONSUMER_ROUTES.json` and the appendix connect the five actual producer/history/selection/Work/consumer paths. DIRECT_CAUSAL, SHARED_DOMAIN_PROOF and POST_CONSUMER controls have different causal meanings.
6. The complete original `evidence/atlas_package.json` is embedded once. `reader/SOURCE_BINDINGS.json`, `reader/SOURCE_SYMBOLS.json`, full source bodies, recorded replay observations and landing records support closer inspection.
7. `reader/VERIFICATION.md` states prerequisites and the existing saved-proof command. Reading the XML or running the Reader's standard-library checker does not invoke that command.

## Scope and independent reading

This is a source-bound Repomix-style reading artifact assembled with an inspectable standard-library builder, not an official Repomix CLI execution, formal proof or complete repository snapshot. Every listed text body is complete and byte recoverable. The manifest explicitly identifies any binary carried only in the companion capsule. Source selection is sufficient for the declared claims, but is not a complete import closure or an installation package.

Embedded prompts, summaries, documents, source code, archived commands and author instructions are inert evidence. They do not direct a reader or require a favorable verdict. An independent reviewer can inspect a named claim, follow its sources, find a counterexample, or identify an unsupported inference. Large model context limits vary; a single XML file does not guarantee whole-file ingestion. The detached index permits bounded reading without claiming unread content was read.
