# Computing, Assembled Around Intent

A real task outlives an individual model response. Finding football pitches is useful only if the permitted dates, surfaces, budget, counterparty conditions and later consent still agree. Planning a wedding is useful only if the arrangement respects the organizer's current conditions. Reviewing photographs remains the same task when an optional audio participant disappears. In each case, the person wants an outcome, not the job of manually transferring every intermediate state between applications.

Radiolaria OS organizes supported computation around that continuing activity. Its execution kernel, RDL Kernel, combines semantic proposals, ordinary programs, bounded services and other computational resources through explicit input, result, time and ownership relationships. The public phrase "Computing, assembled around intent" describes this organization. It does not mean that a new physical computer is fabricated or that an unconstrained model invents any program. An integrator supplies the profile, available capabilities, typed contracts, adapters and policies. The kernel turns a permissible proposal into actual Work and records which results were used. ## From Intent to Governed Activity

Work is a bounded unit of computation whose inputs, execution and result can be identified. Root is the local owner-controlled decision role, not a global supervisor over other owners. DRS denotes the retained-material discovery and retrieval mechanisms, whose contents inform decisions without preserving permission. BSEP, the Bounded Semantic Evidence Packet, is the semantic membrane through which side-specific task material is disclosed. A result records what computation produced; it is not permission to act. [R-ARCH](../PAPER_SOURCE_KEY.md#r-arch), [R-CONTRACT](../PAPER_SOURCE_KEY.md#r-contract)

The useful change is organizational. The person chooses the purpose, significant conditions and consent; the system carries the supported execution relationships through changing circumstances. Applications do not disappear. They can supply a renderer, solver, source, storage service or effect adapter. Only the capabilities needed for the admitted task participate. In EWS, the preview, controls and media services form a temporary environment; ending that environment need not delete an approved result or the history explaining it.

A short football example makes the distinction concrete. The original EXACT request does not yield a complete offer. Allowing only 8 January to move thirty minutes produces three natural-grass sessions for EUR63, within a EUR70 limit. That result is computed work, not a booking. It is wrapped with evidence and consumed by a different local owner. A later BOOK request and its own current decision produce one mock effect. REPEAT and VERIFY inspect the resulting history without another counted effect. The recorded episode explains each object and observation rather than treating the successful price as sufficient proof.

The account now returns to the whole construction. Wedding changes the objective and later two placement conditions, and Work consumes the changed meaning. EWS changes the available environment while preserving photo work. Numerical experience changes which inspection receives scarce Work units. External authorship changes who writes a domain extension while leaving independent examination and source admission in place. These variations are connected by the same distinctions between a proposal, material actually consumed, an applicable result, a local decision and an effect.

## What OS Means Here

Radiolaria is an application execution kernel and reference implementation, not a bootable replacement for macOS or Linux. The accepted technical package contains finite profiles and reviewed reference code. It does not demonstrate autonomous discovery of arbitrary services, arbitrary-code confinement, industrial deployment or universal correctness. Those boundaries specify where the positive result is credible; they are not the product's sole purpose.

The broader design thesis is that capability growth should not entail authority growth. A better model can propose a better plan. A solver can compute a better candidate. An external author can supply a new implementation. None acquires the authority to approve its own consequences merely by being useful. Intelligence and organization complement each other: improving one does not eliminate the need for the other.

This review corpus is bound to accepted technical commit A, not to a new runtime campaign. Its three deep episodes and cross-case comparisons explain recorded results and their exact scope. It offers four entries: understand the argument; verify selected saved evidence; build through the existing engineering interfaces; or read an inert, source-bound packet with an LLM. The publication itself is still an unpublished review proposal.
