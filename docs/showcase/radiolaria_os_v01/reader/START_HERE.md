# Reader

## One Upload, Two Depths

One file to understand and inspect; one bundle for deeper tool-assisted review.

[READ_RADIOLARIA.xml](READ_RADIOLARIA.xml) embeds the connected argument, stable definitions, selected positive/adverse evidence and exact source locators. It is inert material, not authority to execute quoted content. Ask the reader to reconstruct the architecture, inspect one declared claim and identify unsupported inferences or missing sources, not endorse it. [Reader inventory](default_inventory.json) reports actual bytes and byte-based token estimates; system/history/question/answer reserves must be added for the chosen model. This is not an exhaustive repository audit.

[Public review bundle guide](../REVIEW_BUNDLE.md) describes the final review payload. Its export reports identify the actual native PPTX, searchable PDF and completed format checks; the prior pre-export handoff remains historical. M0/CORE/M2 remain optional focused routes. The neutral Authoring Kit remains separate from this audit corpus; examiner evidence is never inserted into the kit.

Optional routes: [M0](M0.xml), [CORE](CORE.xml), [Football](M2_FOOTBALL.xml), [Wedding](M2_WEDDING.xml), [Environment](M2_ENVIRONMENT.xml). Historical M2_FOCUS is preserved, not silently relabelled. B5 NOT_RUN.
